## Outcome

The old reader (`9e988eb`) reports a 4.9536x slowdown on the unchanged SDK capture
of steady update pacing. The corrected reader reports 0.9907x using its recorded
training counter. A separate monotonic clock gives 0.9911x. The deliberately
delayed capture still warns, at 2.8990x; its independent clock gives 2.9027x.
Removing the training counter produces unavailable timing and a `--require-timing`
exit of 2. These are controlled CPU updates on synthetic data, not a production
incident or a hardware benchmark.

The [capture verifier](../scripts/verify_wandb_axes.py) uses standard-library
arithmetic and CLI subprocesses. All 202 SDK history records match the CSVs;
logged coordinates, losses and capture clocks match all relevant members of
the 2,402 retained update observations. The eight scenario checks include six
CSV inputs and explicit selection of each custom-counter input.

## Commands exercised

From the working checkout, and again for Python checks/build in a fresh archive
of `7268b09` with no environment carried over:

```sh
uv sync --locked --all-extras --dev
uv run --locked ruff check src tests examples scripts
uv run --locked mypy src
uv run --locked pytest -q
uv build
uv run --locked python scripts/build_site.py
```

The clean run passed **444 tests in 43.54 seconds**. Mypy checked 27 source
files. `scripts/build_site.py` produces `site/index.html` and 15 report pages.
The three new W&B entries include capture context and embedded CSV downloads.
The dependency lockfile was unchanged.

```sh
uv run python scripts/verify_wandb_axes.py --reports /tmp/wandb-axis-reports
npm ci
TRAINSPOTTER_AXIS_SCREENSHOTS=docs/assets/wandb-axes \
  TRAINSPOTTER_BROWSER_EVIDENCE=docs/verification-wandb-axes-browser.json \
  npm run test:browser

# Serve the built gallery in a second terminal, then exercise its actual links.
uv run python -m http.server 8789 --bind 127.0.0.1 --directory site
TRAINSPOTTER_GALLERY_EVIDENCE=docs/verification-wandb-axes-gallery.json \
  node tests/axis-gallery.mjs
```

The gallery verifier's base URL can be set with `TRAINSPOTTER_SITE_URL`.
`TRAINSPOTTER_INSTALLED_AXIS_REPORTS` can name a report directory generated by
the capture verifier against an installed wheel; it adds four checks of the
explicitly selected custom counter. Those checks are included in the retained
28-workflow record. Without that setting the gallery verifier runs 24 workflows.
It checks served HTML bytes against the local build as well as the CSV downloads.

To exercise a wheel in a fresh environment, install it there with the desired
NumPy version, then run that environment's Python on the verifier:

```sh
/path/to/venv/bin/python scripts/verify_wandb_axes.py \
  --executable /path/to/venv/bin/trainspotter --reports /tmp/wandb-wheel-reports
```

The example's documented `analyze` and `watch --once` commands were exercised.
The unit regressions also check missing/invalid coordinates, ambiguous counters,
custom CSV/JSONL/Lightning coordinates, explicit `_step` assertions and the
chart export's single-axis constraint.

## Scale and limits

A 100,000-row numerical control, 3,962,446 bytes, changes logging interval from
2 to 20 updates while preserving 0.1 seconds per update. The installed Python
3.14 wheel retains all observations and reports a ratio of 1 within floating-point
rounding. JSON completed in 11.47 seconds at 63,416 KiB peak RSS; HTML in 9.15 seconds
at 72,024 KiB, producing a 54,954-byte report. This is one measurement per output
format on 14-logical-CPU WSL2 Linux with 48 GB RAM, concurrent with browser
verification. It includes all loss diagnostics, not just reading and timing.
[Measurement record](verification-wandb-axes-scale.json).

Profiling attributes most runtime to existing sliding loss checks (medians and
plateau slope windows); they were not optimized in this change. Counter names
and explicit `--step-key` are still semantic assumptions supplied by the logger
or caller. The reader cannot reconstruct per-metric axis definitions from CSV,
nor infer why a captured run slowed down. See the [full limits](wandb-axes.md#limits).
